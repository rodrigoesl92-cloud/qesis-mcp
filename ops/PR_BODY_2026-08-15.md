## G-07, autonomous remediation

`ops/G-07_AUTONOMOUS_REMEDIATION.md` and `scripts/selfheal.py` implement the
standing operator instruction: run continuously, repair what the record already
authorises, and stop escalating problems the record already answers.

Three autonomy classes, held as **data in a registry** rather than as judgement
in the moment, each entry carrying the clause that authorises it:

- **A** the record declares the remedy. Apply, reverify, record, continue.
- **B** no declared remedy but a declared safe failure mode. Degrade, record,
  continue. This is D-007 generalised: withheld with cause, never imputed.
- **C** not derivable from the record. Refuse, name the command that settles it,
  never guess.

**Proven, not asserted.** `counts.nodes` was set to `999` in
`data/qesis_graph.json`. The loop detected the mismatch, applied the class A
remedy, reverified, and restored the file byte-identical. A loop never run
against a defect is L-118 family A at the largest scale available.

Locked in `CLAUDE.md` section 2bis, rules SH-1 to SH-6. Scheduled hourly in
`.github/workflows/selfheal.yml`, which runs in GitHub Actions and needs no
local machine. It does **not** promote: promotion requires
`ops/G-07_PROMOTION_POLICY_SIGNED.json`, which is absent, so the runner holds and
says so.

## PUB-1, the percolation finding is published

`data/qesis_percolation.json`. Read from `data/axes/cse_percolation.json`,
recomputing nothing, because a publication step that recomputes is a second
implementation of the analysis and a second chance to disagree with it.

Porthcurno severs **278 cities at removal 13**. Targeted removal reaches 0.3465
of the network where random removal of the same 13 reaches 0.6732. The
single-step severance and the half-collapse threshold at removal 19 are published
as the **separate quantities they are**, so neither is quoted as the other.
Three limitations and a falsifier travel with it.

Closes the second limb of L-056's conditional acceptance of the contagion
framing, which named propagation and a data-estimated tipping point as its two
conditions.

## KG-5, the ontology declares its plane

`EDGE_SCHEMA` carries `physical`, `provenance` or `analytic` per edge type, and
`validate()` refuses a physical edge whose **resolved** endpoint is a provenance
kind.

This is the case domain and range cannot catch. Retype a `CableSourceDataset`
node as a `LandingCity` and `CHOKEPOINT_IN` still satisfies its declaration:
source is a LandingCity, target is a CableNetwork, every field agrees, and the
graph now asserts that a dataset is a place where cables land. Domain and range
blocked that only because no such node happened to exist, which is a fact about
the current node set and not a commitment.

## Merge method

`--rebase`, never squash. `data/vintage_lineage.json` cites commit hashes, and
`verify_vintage_pairing.py` checks that the fields are populated rather than that
they resolve, so a squash would strand the references and pass CI silently. G-05
makes the merge method a governance property here, not a preference.
