The axis exists as `data/axes/v9_sfc_scaffold.json`. It carries a definition that

**So v9.0 is written, gated, and correctly refusing to publish.** It is waiting
on exactly one thing, which no agent can supply: an admissible source covering at
least 27 of 35 states. Everything else about v9.0 is done.

## 4. RDL routing: a solved ticket to a deploying agent

Specification, not a running system. Building it changes
`sovereign-infra/qesis_agents/` and is itself an Article 14 Domain 1 question
(Decisions 1, 2 and 4). It is written here so the build is reviewable before it
exists.

### 4.1 Routing table, failure family to owner

| Family | Signature | Owner | Path to deploy |
|---|---|---|---|
| intake, provenance, licence fitness, coverage | missing metadata, unrecorded licence, coverage below BIG | **SENTINEL** | `validate_intake`, then REJECT or PASS. Never waive |
| publication QA | a claim without an asset id, a caveat stripped in transit | **SENTINEL** | `gate_publication`, BLOCK is final until the cause is removed |
| chain, hashes, integrity | attestation, spine, `index_sha256` | **SENTINEL** | `verify_chain`, then ARCHITECT lands the fix |
| gate or CI defect | a check measures the wrong property | **ARCHITECT** | gate module plus two fixtures, per V-2 |
| calibration, statistics, robustness | anchors, PRI, necessity, sensitivity | **ANALYST** | re-run script plus evidence JSON in `ops/analysis/` |
| sourcing, freshness, untrusted content | a source ages out, a page carries instructions | **SCOUT** | intake package, then SENTINEL |
| documentation, register, runbook | a process ran twice without a runbook, a stale status doc | **ARCHITECT** | `technical_documentation`, `reconcile_register` |
| public artefact, funnel, SEO | a finding is cleared and unpublished | **HERALD** | `artifact_ladder`, only from SENTINEL cleared material |
| contract, GDPR, licence enforcement, obligation | an NDA arrives, an obligation is created | **COUNSEL** | `triage_contract`, `record_obligation`. RED means external counsel |
| credential exposure | a secret reached a log, a chat, a sync folder | **HUMAN only** | rotation. G-03, G-04. No agent participates |
| promotion, vintage move | the world's copy changes | **HUMAN only** | G-06. Merge may be delegated, promotion never |

### 4.2 Escalation ladder

Tone rises with how many times the ecosystem has already paid for the lesson.

| Occurrence | Response | Artefact |
|---|---|---|
| 1st | Record with the corroborating detail | `L-` entry |
| 2nd | Wire it. The rule becomes a gate with one fixture it must refuse and one it must accept | gate module plus fixtures in `test_gate.py` |
| 3rd | Block it. The gate becomes a required check and promotion refuses while it fails | CI required check |
| 4th | Escalate the design. Recurrence is evidence the control sits in the wrong layer, not that the operator is careless | `D-` decision entry |

The ladder climbs on the **family**, never on the person. Attribution is data,
not blame (R-1), and a good outcome reached by a wrong process is a defect (R-3).

### 4.3 What a routed fix must carry

1. the `L-` id it answers,
2. the command and the value that demonstrate the defect,
3. the fixture that would have refused it,
4. the surfaces it touches, enumerated in code and read back before commit
   (L-058),
5. the branch, per G-06: `feature/*`, `patch/*`, `fix/*` or `docs/*`, reaching
   `main` through a pull request,
6. a human name for anything that promotes, spends, grants privilege or touches a
   credential.

A fix that cannot produce item 3 is a patch, and it is recorded as one.

## 5. Boundaries COUNSEL holds

Stated because the instruction was to add plugins and skills whenever useful, and
permission was given.

- COUNSEL **installs nothing and promotes nothing.** It proposes a plugin or
  skill with the specific gap it closes, and Rico installs. Article 14 Decision 2
  is *self modification constraints for local agentic scripts*, risk CRITICAL,
  unsigned. An agent that extends its own toolset is inside the boundary that
  decision exists to draw, and the permission to use a tool is not the same act
  as the permission to acquire one.
- COUNSEL **does not sign.** Nothing in the Article 14 register is signed by an
  agent. The gate exists precisely so that a person decides.
- COUNSEL **does teach.** Where a concept is not landing, it explains from first
  principles with a worked example, then returns to the case, and it summarises
  the week's learnings on Fridays.
- COUNSEL **routes integrity findings to SENTINEL.** It is the second opinion
  behind SENTINEL on licences, not the gate. Inverting the two was L-078.
