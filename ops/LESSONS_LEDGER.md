Every mistake becomes a rule. Agents and orchestrator MUST read this file at session start; new entries are appended, never edited. This is the practical RAG layer: retrieval happens by reading this file before acting.

Format: `L-### · date · what happened → the rule now in force`

**L-016 · 2026-07-28 ·** The first commit gate found literal fallback credentials in four files that had been sitting in the working tree since the Docker phase: a Postgres password, a pgAdmin password and a Jupyter token, two of them printed to the console by the update script. **L-017 · 2026-07-28 ·** L-013 diagnosed the zero-byte `qesis.sqlite` as OneDrive dehydration and prescribed pinning. The diagnosis was wrong: the file has zero blocks allocated, a forced read does not hydrate it, and writing SQLite to that path fails outright with `disk I/O error` because the sync-backed mount does not provide the locking and rename semantics SQLite needs. **Rule:** databases are never placed inside a sync folder; the live SQLite lives in `sovereign-infra\var\` and only byte-identical read-only snapshots are copied into OneDrive. Second-order rule: when a fix is prescribed for a symptom, the diagnosis is verified by reproducing the failure before the fix is scheduled, not after it fails again.

**L-018 · 2026-07-28 ·** Reciprocal rank fusion was applied to a single ranked list. With the dense half unavailable (Ollama down), RRF collapsed to 1/(60+rank), so every query in the first retrieval probe returned the identical scores 0.0164, 0.0161, 0.0159 regardless of what was asked. Ranking order survived; every trace of match strength was destroyed, and a confidence signal built on those numbers would have been noise presented as measurement. **Rule:** rank fusion is for combining two rankings whose scores are not comparable. With one ranking, carry the normalised score through, so a weak best match stays visibly weak and a caller can threshold on it.

**L-019 · 2026-07-28 ·** The corpus indexed CSV tables as profiles only: name, columns, six sample rows. Searching `QES-A0031` returned nothing at all, and so would every ISO3 code, cable name and decision reference in the corpus, because identifiers live in row bodies. Compounding it, `collect()` relabelled the asset register's `source_kind` to "register" after construction while the chunker only took the row path for "table" and "dataset", so the register silently fell through to the prose chunker and lost its rows a second time. **Rule:** identifiers live in rows; index row bodies up to a declared cap and state plainly which tables were profiled instead. And when a field that drives dispatch is reassigned after an object is built, re-check every branch that keys on it.

**L-020 · 2026-07-28 ·** HERALD's first lead run paired European Commission DG CONNECT and ENISA with Bahrain and Saudi Arabia, because the scope test treated an EU-scoped body as relevant to every country and the Gulf states score highest on composite exposure. Thirty-six leads, the top eight of them nonsense. **Rule:** jurisdictional scope is checked against membership, never treated as a wildcard. A lead register that has to be filtered by hand before use is a list, not a register.

**L-021 · 2026-07-28 ·** The database rebuilt under D-027 loaded each spreadsheet dump verbatim: the sheet title became column one, the remaining columns became `c1..cN`, and the real header stayed in data row 1. The 2,555 rows are intact and correct; the schema tells you nothing about them, and any aggregate that forgets to exclude row 1 silently mixes a header string into the computation. **Rule:** a load is not finished when the rows land. It is finished when the columns are named and row 1 is either the header or the data, never ambiguously both. Header resolution is available as a stopgap through ANALYST `tables`; the durable fix is promotion in the loader.

**L-022 · 2026-07-28 ·** The six subagent definitions were given a Runtime section instructing them to call `qesis_agent_run` and `qesis_search`, while their `tools:` frontmatter still granted only Read, Grep, Glob, Bash and Write. Every one of those instructions was unfulfillable, and nothing would have failed loudly: the agent would simply have reasoned from memory and produced something plausible instead of calling the tool. **Rule:** an instruction to use a capability ships together with the grant of that capability, in the same change. When writing an agent definition, the last check is whether the tools named in the body appear in the frontmatter.

**L-023 · 2026-07-28 ·** The KPI table reported `pages_published: 10` on a week when nothing was public. The counter had been wired to the count of `content_artifacts`, which are drafts, most of them still held by Article 14. A number that reads as traction while the truth is zero is worse than a blank cell, and it was generated by the agent whose own charter says a drifted definition is a finding. **Rule:** every KPI carries its definition next to it, and a counter reports the thing it is named after. Drafts are counted as drafts.

**L-024 · 2026-07-28 ·** The first repo-wide em dash repair converted a table cell holding a bare dash into a stray comma, producing a malformed row in the operations manual. The doctrine explicitly exempts that case: a bare dash survives as a null-value placeholder inside a data table. A second defect in the same pass replaced the character without consuming its surrounding spaces, leaving a double space behind, and a third would have deleted the doctrine's own definition of the rule it was enforcing. **Rule:** an automated repair carries the exemptions of the rule it enforces, or it is not enforcing that rule but a cruder one. Repairs run through `style.repair_em_dashes`, which honours the table and self-reference exemptions, and the standing gate is `SENTINEL doctrine_audit`, not a grep.

**L-025 · 2026-07-28 ·** The doctrine gate flagged `WRITING_STYLE.md` and `AGENT_ACCEPTANCE_TESTS.md` for containing banned words, which they contain because one defines the banned list and the other describes the failure conditions that quote it. A gate that fires on the rulebook is a gate that gets switched off within a week. **Rule:** a term named inside quotation marks is cited, not used, and the scanner ignores it; a document that defines a list is exempt from being scanned against that list, and the exemption is declared in the output rather than hidden in the code.

**L-026 · 2026-07-28 ·** Two index passes overlapped and left 74 duplicate chunks in the retrieval store. The effect was not a warning but a silent quality loss: duplicates occupy separate slots in the top-k, so one query returned the same document three times and crowded out every competing source. Nothing in the pipeline noticed. **Rule:** a retrieval index carries a uniqueness constraint on its natural key, so a concurrent write fails loudly instead of degrading ranking quietly. `(doc_id, ordinal)` is now unique.

**L-027 · 2026-07-28 ·** When the dense half of retrieval came online, every query began reporting low confidence regardless of quality. The confidence bands had been calibrated against normalised BM25, which tops out at 1.0, while fused RRF tops out at 2/(k+1), or 0.0328. The scores were correct and the interpretation was nonsense. **Rule:** a threshold belongs to the scale it was calibrated on. When a scoring method can change at runtime, the response names the scale in use and normalises before judging.

**L-028 · 2026-07-28 ·** The August connector authenticated and listed its organization while every org-scoped endpoint returned 401 for missing WorkOS claims. **L-029 · 2026-07-28 ·** Two thirds of the asset register could not be re-verified from disk, because the origin of most assets is a sheet inside a workbook rather than a standalone file. Coverage looked perfect while auditability sat at 27 percent, and no internal check noticed, because every layer was consistent with every other layer and none of them could be recomputed. **Rule:** the register carries two distinct claims in two distinct columns. `sha256` records what was ingested. `verify_sha256` records an artifact that can be recomputed from disk today. A derivative may witness for itself and never for its source, and adding the second claim must not silence the first: the ingest-hash check still runs and still reports drift separately.

**L-030 · 2026-07-28 ·** Every search across `OneDrive - ESIC\Archivos de Microsoft Copilot Chat` returned nothing, and the folder appeared not to exist, while a directory listing showed it plainly. **L-031 · 2026-07-28 ·** The integrity audit was run while a reindex was mid-flight and reported 42 coverage gaps, because the rebuild deletes chunks before writing them. **L-032 · 2026-07-29 ·** A composite asset registered as a manifest over three named files was verified by globbing the directory that contained them. **L-034 · 2026-07-29 ·** The closing status report was written, then blocked by the doctrine gate for the word "unlock" in its own improvement-loop section, one paragraph after describing the gate as a standing control. **Rule:** the gate runs on every artifact before delivery, including the ones about the gate. **L-036 · 2026-07-29 ·** A Notion integration token was pasted into the working chat in plaintext, alongside a request to use it. **L-038 · 2026-07-29 ·** Branch protection was reported as blocked behind a paid plan and left as a ticket for Rico to buy his way out of. He pushed back and asked for another route, which was the right call: only one API had been tried. Rulesets were tested next and refused identically, which confirmed the constraint was real, and that confirmation is what made the alternative defensible rather than lazy. **L-039 · 2026-07-29 ·** Claude Desktop refused to attach the agent server, and the log named two distinct faults rather than one. `ModuleNotFoundError: No module named 'qesis_agents'` because Desktop honoured `cwd` for the process but did not place it on `sys.path`, so `-m package.module` had nothing to import. Then `spawn py ENOENT` on retry, because `py` is a WindowsApps alias that resolves in an interactive shell and not in Desktop's spawn environment. **Rule:** a host that spawns a server gives it neither your PATH nor your working directory. Invoke by absolute interpreter path and absolute script path, and have the script compute its own root from `__file__` rather than trusting either. Diagnostics go to stderr, never stdout, because stdout is the JSON-RPC stream and printing to it corrupts the session.

**L-040 · 2026-07-29 ·** Agent definitions in `.claude/agents/` are a Claude Code feature and Claude Desktop does not read them at all. Desktop reaches agents only through MCP. The two surfaces also read different config files, so a server registered in a repository's `.mcp.json` is invisible to Desktop, which reads `claude_desktop_config.json`. For two days the agents were reported as available on both surfaces when they were only available in Code, and only inside one folder, because there was no user-scope copy either. **Rule:** state which surface a capability is available on, and verify it there rather than inferring it from the other.

**L-041 · 2026-07-29 ·** The cloud vault push failed with an authentication error that was not an authentication problem. The machine had 151 MB free of 6 GB, `gh` died with a Go allocation failure, and git could not fork its credential helper, which surfaced as "could not read Username". **Rule:** read the resource state before believing an error message. Under memory pressure, tools fail with whatever error their failing subprocess happens to produce, and chasing that message wastes the time the real constraint is already costing.

**L-042 · 2026-07-29 ·** The first full-state backup made the doctrine gate report eight violations that did not exist. All eight were backup copies of governance files that are exempt where they actually live, and the gate was scanning the write area as though it were source. The failure mode this invites is worse than the false positive: an automated repair would have edited the backups, destroying the one property a backup has, which is fidelity to what was backed up. **Rule:** a gate scans sources, never copies. Exclude the write area, fix the original, and let the next backup carry the fix forward. Any control that can modify a backup is a control that can corrupt a restore.

**L-043 · 2026-07-29 ·** The Desktop launcher was declared fixed after it started cleanly and exited zero. Starting is not attaching: a server that boots and then fails its handshake looks identical from the outside. `scripts/drive_mcp.py` now speaks the real protocol from a neutral working directory, initialize through tools/call, and only a passing drive counts as evidence. **Rule:** prove a server works by being its client, not by watching it launch. The same distinction applies to every integration in this ecosystem: the question is never whether the process starts, it is whether the other side gets an answer.

**L-044 · 2026-07-29 ·** A five-service cloud migration was proposed to solve a memory problem, and four of the five would have solved nothing while starting a monthly bill. Cloud Build duplicated a GitHub Actions pipeline that already ran free and green; Cloud SQL and Cloud Workstations bill monthly against a 25 EUR one-time memory upgrade; Cloud Run could not move without the data, and moving the data was the paid item. Only Cloud Storage addressed the actual failure, which was that `gh` and `git` both fork and there was no memory to fork into. **Rule:** price each service against the specific failure it removes, not against the discomfort that prompted the search. A plan that is right about the symptom can still be wrong about every remedy, and the cost of finding out later is a subscription rather than an afternoon.

**L-045 · 2026-07-29 ·** The sovereignty index measures dependency on foreign hyperscale infrastructure across three of its seven axes, and the proposed fix was to move the index onto foreign hyperscale infrastructure. Storing encrypted backups there is narrow and defensible; moving the runtime is not the same decision and would put the instrument inside the exposure it measures. **Rule:** when the product is a critique of a dependency, adopting that dependency is a governance decision with a decision number, never an infrastructure convenience. State it before, not when a reviewer asks.

**L-046 · 2026-07-29 ·** The agents had run 422 logged actions with 41 of them held at the human gate, and neither surface showed any of it. Claude Code prints the return value of whatever was just called, the desktop client renders a chat transcript, and the store that holds the truth is a file nobody looks at. The gap was not a missing feature in the host, it was the assumption that a host which can invoke agents will also show them. It will not, and waiting for it to is how a governed system quietly becomes an ungoverned one. **Rule:** a runtime that logs its own behaviour owes itself a surface that reads that log, built by the operator and not by the vendor. The surface is generated from the store on every run, it recomputes what it reports rather than quoting the runtime's own verdict back, and where it cannot reach live data it stamps the reading time instead of implying one. An observability layer that trusts the thing it observes is decoration.

**L-047 · 2026-07-29 ·** The agent console shipped with an invisible topology diagram. Every node in the SVG was painted with `fill="var(--card)"` and `stroke="var(--cool-500)"` written as presentation attributes, which the CSS custom properties specification does not substitute: `var()` resolves only inside CSS declarations. Browsers discard the attribute, `fill` falls back to its initial value of black, and six black rectangles with black labels sat on a `#141b2b` ground looking like nothing at all. Four gates ran on that file and all four passed, because the writing doctrine reads prose, the hot accent check counts occurrences, and neither of them looks at whether a colour actually arrives. The rule the design system already carries, that nothing but `tokens.css` declares a colour, was obeyed to the letter and broken in effect, because a token written where it cannot resolve is not a token, it is a typo with good intentions. **Rule:** paint an SVG from the stylesheet, never from presentation attributes, and assert it at build time rather than trusting review. `assert_no_var_in_attrs` now blocks the write, and the same guard buys the print inversion for free, since a diagram styled by class inherits the media query while a diagram styled by attribute cannot. The wider rule: a gate that checks the text of an artifact is not checking the artifact. Verify the property you care about, which here is whether the thing renders, not whether the source mentions the right words.

**L-048 · 2026-07-30 ·** The repair for L-047 was written inside `scripts/build_console.py`, which fixed one surface and protected nothing else. Two other generators produce public HTML from the same token system and neither would have caught the same defect, because the check existed as five inline conditionals in one file rather than as a shared control. That is the shape that produced the original bug in the first place: a rule held in prose and applied by hand. **Rule:** a gate is a module that generators import, never a block they copy. Copied checks drift, and the drift is invisible until the surface they guard is already wrong. `qesis_agents/render_gate.py` now holds nine gates behind one `run_gates` call, `scripts/verify_surfaces.py` runs the same nine over everything already sitting in `site/` so a file that arrived by hand or by restore is caught too, and the doctrine is written once in `ops/RENDER_CONTRACT.md` and indexed for retrieval. Prevention and detection are separate halves and both are cheap: prevention refuses the write, detection asks whether anything got in another way. An exemption is a named entry with a reason in `KNOWN_EXEMPTIONS`, and the target state for that dictionary is empty, because a permanent exemption is a rule that was quietly deleted.

**L-049 · 2026-07-30 ·** Three render gates were shipped, registered as assets, cited in a decision entry, and run over three surfaces. All three passed. All three were measuring the wrong property. `offline` matched the string `href`, so it flagged all 34 primary source citations on the method page as outbound requests, which made the doctrine contradict itself, because the same doctrine requires sourced data: cite your sources, and never link to them. The same gate missed `@import`, a CSS `url()`, a form action, a script calling `fetch`, and a `file:///C:/Users/Lenovo/OneDrive/...` link that published the author's home directory into the navigation bar of a public page, because it looked for `//` after an optional `http:` and `file:` is neither. `doctrine` refused every verdict that was not PASS, but `style.scan` reserves BLOCK for the hard rules and returns REVIEW when a human should look, so an advisory hit blocked a build and printed `doctrine REVIEW: []`: a refusal naming no offender, which cannot be fixed and will be switched off. The advisory hits were two JavaScript ternaries, `z < -700 ? 0 : 1`, read as rhetorical questions, because the prose scanner was handed the whole body including `<script>`, and `_strip_code_and_tables` strips Markdown fences and never HTML. `hot_accent` counted occurrences of the characters `var(--hot)` and subtracted the token file, reporting 3 for a page rendering 7, because a stylesheet rule has spent nothing until an element carries the class and one rule can paint forty rows. **Rule:** a gate that reports the wrong number is worse than a missing gate, because a missing gate is visibly missing. A gate is a claim about a property, and an untested gate is that claim merely asserted. Every gate now owns fixtures in `scripts/test_render_gates.py`, one input it must refuse and one it must accept, and the final case is the control on the control: a gate added to `GATES` without both fixtures fails the suite, so coverage cannot be quietly skipped because skipping it is the failure. Two of the fixtures exist because the repair introduced its own defects, both found by the suite rather than by review: a CSS comment above a rule was captured by the selector pattern and its commas split the selector into fragments matching nothing, so a documented rule became invisible and the gate read 0 hot elements on a page with exactly 1; and an id selector carried no tag and no class, so the vacuous subset test matched every element on the page. This is L-023 one level up, in the controls rather than in the reporting: a counter reports the thing it is named after, including when the counter is a gate.

**L-050 · 2026-07-29 ·** `config.CANONICAL_VINTAGE` was the literal `"v8.0"` while the canonical index had moved to v8.2. Every consumer that fell back to the constant reported a version two releases dead, and the acceptance battery asserted the same literal, so the test went green precisely because both were wrong together. A constant that names a moving value is a defect with a delay fuse: correct the day it is written, wrong at the next release, silent in between. **Rule:** derive a version from the artifact that carries it, and keep a literal only as an unreachable fallback. A test that asserts a hardcoded version is testing that a string is present, not that the version is right, and it will confirm the drift rather than catch it.

**L-051 · 2026-07-29 ·** The `offline` gate refused `<link rel="canonical">`, treating a declaration as a fetch. It was the same false positive the gate had already been fixed for once with anchors: a rule written against a tag rather than against the behaviour that tag produces. A canonical link loads nothing; it states the document's preferred address. **Rule:** gate the behaviour, not the element. When a gate refuses something the doctrine elsewhere requires, the gate is wrong, and that contradiction is the fastest signal available that it is measuring the wrong property.

**L-052 · 2026-07-29 ·** The first `citation_scan` run found a defect on its first execution: `console.html` carried neither structured data nor a canonical, because two surfaces had been wired and a third forgotten. The scan was written to check three and found the gap immediately. **Rule:** a check written to cover a set finds the member you forgot, which is most of its value. Enumerate the set in the checker rather than in your head, and let the first run be the inventory.

**L-053 · 2026-07-31 ·** An expansion proposal built its flagship publication on a bivariate result between two axes derived from the same count. CRD was `100*(n_regions-1)/18` and ODI was 100 times the Herfindahl index over provider shares of those same regions, so the published curve was the hyperbola `ODI >= 10000/(100+18*CRD)`, tight for 24 of 35 states, and the reciprocal transform recovered Pearson +0.92 from a reported -0.50. The proposal then asked why six states sat at ODI 100 with CRD near zero and answered with a causal story about nascent cloud adoption; those six states have one region each and the Herfindahl index of one region is 1.0 by definition. The same document audited seven files as though all of GRID had been read when the folder held thirty-eight and two of the seven were not in it, classified five of seven as ENHANCE against a true rate of one in five, and put a percentage in its abstract, 28.6 of EU states passing an Article 17 substrate audit, that appears nowhere in the dataset and has no denominator. Every one of those defects is the same defect: a claim stated with more confidence than its derivation supports, in a document whose fluency made checking feel unnecessary. **Rule:** before a correlation between two internal axes becomes a finding, derive each axis back to its raw input and ask whether they share one.
